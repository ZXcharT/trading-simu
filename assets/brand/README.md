# OneChart brand assets

These public display assets are exact or derived exports of the canonical OneChart brand set established in private source commit `ce0b98296133dead54a61a2ebe2cf2a612cbb2a6`.

Canonical asset hashes:

- black Symbol SVG: `3fcf81384822325e7d88bd84e655cd821548941b33eedf60952f8720dacbd318`
- white Symbol SVG: `861db6a197a8b3ac340905606a3d8239e6fca47c9c6bf7ee9f83b739974c06f4`
- black horizontal Lockup SVG: `68630d9dd909a78d4b61173dac83bcf2b8023652e8bc74a4907f95d22b8b16b2`
- white horizontal Lockup SVG: `b1538c83304e44030286ea77dd91789cc6f3ec25700e0a94276c11cc8e1bc9e8`

The horizontal Lockup contains the Futura Medium wordmark as vector outlines. The adaptive SVG favicon, Open Graph image and neutral-paper PWA app icon are web-specific derivatives. `onechart-app-icon.svg` is the source for `icons/icon-192.png` and `icons/icon-512.png`.
